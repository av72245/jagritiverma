# Jagriti Verma, portfolio prototype

A single-file animated portfolio prototype for Jagriti Verma (Melbourne lifestyle creator and mortgage broker).
No build step: everything is in `index.html` (fonts load from Google Fonts).

## Preview locally

    python3 -m http.server 8000
    # open http://localhost:8000

## Deploy

Any static host works. Point it at the repo root, with no build command and `index.html` as the entry.

- **Vercel / Netlify / Cloudflare Pages:** import the repo, leave build settings empty.
- **GitHub Pages:** Settings, Pages, deploy from branch `main`, folder `/ (root)`. (Free GitHub accounts need a public repo for Pages.)
